# Black Friday — Giotto Mobilidade

As três artes originais vieram de `Mobilidade.rar`. Todas são PNG de 1672 × 941, preservadas com os nomes e o conteúdo originais.

## Artes

- [Bis Elétrica](artes/bis_eletrica/)
- [Banner Mobilidade Elétrica](artes/banner_mobilidade_eletrica/)
- [Banner Mobilidade](artes/banner_mobilidade/)

## Fluxo de trabalho

1. Use o PNG em `01_arte_original` como fonte da arte correspondente.
2. Quando chegar o prompt de separação, registre-o em [prompts](prompts/) e guarde os itens separados da arte em `02_elementos_separados`.
3. Quando chegar o prompt de animação, registre-o em [prompts](prompts/) e guarde os arquivos editáveis da animação em `03_projeto_animacao`.
4. Exporte os MP4 aprovados para [videos_finais](videos_finais/) e envie os links para download.
